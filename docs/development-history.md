## 技能、MCP、定时任务与打包进展

- 技能支持导入本地目录、启停和移除；对话与定时任务可选用技能，说明内容由 Pi 的技能机制展开。当前不执行技能脚本。
- MCP 支持本机 stdio 和无认证 HTTP 配置、启停和单次选择；工具调用通过 Pi 官方扩展并逐次确认。服务进程本身在启动时不受沙箱隔离，不支持环境变量、密钥和 OAuth；定时任务尚不调用 MCP。
- 定时任务支持五字段 Cron、时区、启停、编辑、立即运行、错过及重叠记录和查看对话。仅应用运行时调度；计划任务仅使用模型和可选技能说明，不读取项目文件。时钟变化、重启和实际窗口操作仍需端到端验收。
- 参考 Skillkit 添加 electron-builder macOS ARM64 DMG/ZIP 配置，暂不签名或公证；ARM64 DMG、ZIP 及应用目录已生成；独立应用启动存活并可加载打包的 Pi SDK。正式安装、升级、打包后对话及各功能、最低系统版本仍需验证。
- 构建、30 项 Node 自动测试以及 Electron 工作进程模拟网关测试通过，涵盖 MCP 授权与拒绝；不能替代真实网关、完整窗口和目标系统验收。
- 账号系统、Web 历史同步及服务端续接尚未实现，接口按既有约定暂不设计。Pi 的本地文件操作、沙箱隔离、Office 真实样例验收也尚未完成。

## 客户端自动更新与发版流水线（2026-11-08）

- 参考 SkillKit 主界面的 check/update 控制模式，为客户端增加应用自身的自动版本发现与整包更新（插件自动更新暂不做）：主进程经 GitHub Releases latest（robotbird/piwork-desktop）发现新版本，启动约 3 秒后静默检查（`<userData>/app-update-state.json` 24 小时节流），设置 → 关于 → 软件更新卡片提供手动「检查更新 / 下载更新 / 打开安装包」；发现新版后主界面侧栏底部露出「新版本 vX.Y.Z」入口，点击直达关于页。
- 更新器分两层：`electron/app-update-core.ts` 纯函数（semver 比较、DMG 资产挑选、release 解析、节流记录校验，node --test 直测）与 `electron/app-update.ts`（fetch 发现、流式下载到 `<userData>/updates/`、按 GitHub 资产 digest 做 sha256 校验、无 digest 退化为 size 校验、进度节流推送、取消、同版本免重复下载、旧包清理）；应用未签名（identity:null），安装方式为打开 DMG 由用户拖入 Applications，不做自动替换。IPC 走 `app-update:*` + `app-update:changed`（仿 sync 模式），`PIWORK_UPDATE_API` 可覆盖更新源供测试注入。
- 新增发版流水线 `.github/workflows/release.yml`：推 `v*` tag 在 macos-14 构建，校验 tag 与 package.json 版本一致后 `pnpm release:mac`（electron-builder --publish always）发布 Release（DMG/ZIP/latest-mac.yml）。
- 验证：`pnpm build`、97 项 Node 测试（新增 app-update.test.mjs 5 项）、desktop-e2e、新增 `tests/app-update-e2e.mjs`（本地 mock：自动发现、侧栏提示、取消下载、坏 sha256 拒绝、正常下载与免重复下载、stub shell.openPath 打开安装包、无新版回退）通过；关于页两种状态（可下载/已就绪）经真实窗口截图核对。GitHub Actions 实际发版与旧版本自动发现待仓库具备发版条件后演练。
