# piwork Desktop MVP 精简开发计划

更新时间：2026-11-05  
依据：[MVP 需求](mvp-prd.md) · [设计规范](design-system.md) · [技术设计](technical-design.md)

本表是当前开发的任务状态清单。按桌面办公主流程拆分，每完成一项更新状态和验证方式；旧计划及 E11、E12 的细项保留在[精简前计划归档](development-plan-archive-2026-11-04.md)，不再作为当前逐项执行清单。

状态：**已完成**表示该行范围已经实现并验证；**部分实现**表示仍有明确缺口；**未开始**表示尚未实现；**待联调**表示需求保留，但当前依赖的服务端方案尚未安排。完成的基础能力不代表完整产品已完成。

## 版本范围

- 首发 macOS 13 及以上 Apple Silicon，Electron 架构和打包方式参考 Skillkit；界面与交互以 piwork Web 为基准。签名与公证暂不纳入。
- 优先交付本地可用的办公闭环：选择项目、配置自定义网关、对话处理文件、预览成果，以及技能、MCP、定时任务和基础设置。
- Web 账号、账号模型能力、最简单的历史同步与 Web 继续任务仍是完整 MVP 需求；Web 登录、模型目录及账号模型代理已接入；双向同步正在跨端验收，不能因本地版完成就宣称完整 MVP 已完成。登录后的用量限制以服务端为准；未登录自定义网关不由客户端设限。
- 本地元数据首版继续使用现有 JSON 和 Pi JSONL，确保正常重启保留；不把 SQLite 迁移、自动恢复和备份管理作为本地版前提。E10–E12 原型保留，尚未接入应用，不删除或覆盖已有数据。若以后切换数据库，必须先保留旧数据、验证迁移后再启用。
- Gondolin 隔离、复杂同步冲突处理、独立后台调度和高级 Office 编辑放在后续；当前不宣称已有操作系统级沙箱。

## 已完成：MVP-06 对话基础

- 需求：与 piwork 的对话体验保持一致，用户能停止流式回复、查看保留下来的内容、继续发送，并可重命名或删除历史对话。
- 异常：模型或技能启动失败后结束加载状态并显示可理解的提示；不在界面显示网关或技能的原始敏感错误。
- 验证：使用隔离数据目录和模拟网关，在真实 Electron 窗口覆盖停止、继续、重命名、删除、重启及失败；真实网关验收仍属于 MVP-05。

## 已完成：MVP-07 办公文件任务

- 在对话关联项目后，用户发起整理资料等任务，Pi 可读取已选项目内资料并生成或修改成果，右侧可浏览和预览结果。
- 模型请求写入或修改前显示目标文件并等待用户确认；用户拒绝或取消则不执行。读取和写入范围、文件大小及路径校验以可验证的实现为准，不将其称作系统沙箱。
- 优先复用已安装 Pi 版本的工具、扩展和事件机制；不默认开启 shell 或未明确支持的工具，保留现有 MCP 单次确认。
- 使用临时项目和模拟模型验证读取、创建、修改、拒绝、越界路径和重启；对话中最基本的执行状态展示与 MVP-08 一起完成。

## 已完成：MVP-11 本地技能

- 对照 Web 技能页的信息层次、搜索与卡片，桌面端提供本地技能目录导入、详情、启停和从列表移除；不接入服务端市场。保留源文件，任务中只提供已启用的技能。
- 使用当前安装版本的 Pi 技能发现和 `/skill:name` 扩展；模型可读取所选技能目录下的 UTF-8 文本资源（最多 1 MB），路径检查拒绝越界和符号链接。Pi 官方 Bash 工具按调用逐次请求确认；运行在本机用户权限下，不受操作系统沙箱保护，可访问用户有权访问的文件和网络。
- 验证：`tests/skill-tools.test.mjs` 覆盖资源读取、越界和命令拒绝/允许；`tests/skill-execution-e2e.mjs` 在开发版及 ARM64 包覆盖导入反馈、选择、拒绝和允许执行、停用后重启、移除及源文件保留；`tests/desktop-e2e.mjs` 覆盖搜索和详情。
- 2026-11-04：本机默认 macOS 27 SDK 与链接器不兼容，设置 `SDKROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX15.4.sdk` 后，原生依赖重建和 ARM64 打包成功；打包后技能及 SQLite 测试通过。安装升级和 macOS 13 实机验收仍属于 MVP-17。

## 已完成：MVP-12 本地 MCP

- 本地保存 stdio / 无认证 Streamable HTTP 服务配置，支持新增、编辑、启停和移除；密钥、环境变量及认证尚未支持，不应在配置里填写密钥。
- 通过 Pi MCP 客户端在独立进程测试连接、展示工具及失败提示；测试超时关闭连接和本地服务。用户发起工具调用时逐次显示目标及参数并等待确认；本地服务运行在当前用户权限下，不受操作系统沙箱保护。
- `tests/mcp-execution-e2e.mjs` 在开发版及 ARM64 包覆盖 stdio/HTTP 连接及工具调用、工具列表、失败、拒绝写入、超时进程清理、编辑启停、重启恢复和移除；调用使用模拟模型网关及本机 MCP 测试服务。连接测试完成后会断开，因此界面文案显示“连接测试成功”。

## 已完成：MVP-13 本机定时任务

- 支持每天、每周和自定义 Cron、时区、项目、技能和 MCP；应用运行时调度，退出或休眠期间不保证触发，恢复后记录错过而不补跑。
- 使用已配置的模型网关和 Pi 工作进程。项目写入、技能命令和 MCP 调用需要用户确认；确认最长等待两分钟，未获确认不会执行。命令和 MCP 在本机用户权限下执行，不受操作系统沙箱保护。
- 支持创建、编辑、暂停、恢复、删除和立即执行；任务历史展示状态、错误及相关对话，删除计划不终止已运行任务。网关绑定当前已配置的单个自定义网关，变更后需重新保存任务。
- 验证：`tests/desktop-e2e.mjs` 和 `tests/schedule-execution-e2e.mjs` 在开发版及 ARM64 包覆盖计划编辑、自动触发、错过记录、权限拒绝、网关和项目失效、重叠跳过、运行中删除、从历史打开对话及 MCP 子进程退出；并通过模拟休眠事件验证短暂休眠后不补跑、显示全部已保存记录。测试使用隔离数据和模拟网关。真实网关验收仍属于 MVP-05。

## 已完成：MVP-14 Web 账号

- 桌面设置可配置 HTTPS Web 服务地址（本机测试允许 HTTP），在隔离窗口使用现有 Web 登录；会话保存在独立 Electron 分区，支持查询当前账号、权限过滤后的模型列表和退出，应用重启后恢复。对话中选择账号模型或独立的自定义网关，已创建的对话绑定模型和来源。
- 账号模型经本机受限转发和 Web 的 Pi 消息流代理调用，Cookie 不交给界面或 Pi 工作进程。Web 对每次模型调用执行账号、角色及额度检查，记录服务端用量；其他部署需先应用 `0025_desktop_inference_usage` 迁移。本地定时任务目前仍使用自定义网关。
- 验证：`tests/account-e2e.mjs` 使用隔离数据验证登录、目录、账号模型流式多轮、额度错误、重启和退出；Web 的 `tests/e2e/desktop-inference-http.mts` 在隔离数据库验证授权、流式和额度。使用本机真实 Web 账号、DeepSeek 模型完成桌面 Pi 对话，并核对服务端记录。

## 进行中：MVP-15 基础历史同步

- [x] 复用 Web 账号和现有接口查看普通对话，并可导入为独立本地副本。
- [x] Web 最小同步接口、桌面文本队列、冲突检测和跨端运行互斥；不自动上传附件、工具内容、本地路径或项目资料。
- [x] 用户确认旧任务及其进程停止后，可同步中断时已记录的输入并解除运行锁，不自动重跑。Web 增加本地资料不可用提示。
- [x] 使用真实账号、模型及数据库，经独立 Web 进程验证桌面发起、Web 继续和桌面接收新消息；隔离测试覆盖鉴权、冲突、互斥、重启和中断恢复。
- [ ] **核心验收：离线与互斥**：无可靠服务端锁时阻止同一同步任务执行并保留草稿，不自动重跑；已完成的待同步记录保留并在联网后重试。验证断网、恢复及重复请求。
- [ ] **核心验收：身份与冲突**：登录失效或账号切换时保留队列；历史不一致时保留两端内容并提示，不自动覆盖。验证重启及多端竞争。
- 后续迭代：跨端同步运行终态和完成时间、标题修改同步，以及同步对话的本地/云端删除管理。现阶段同步对话禁止删除，以保护待同步队列；任务进行中、异常中断和同步状态已有基础提示。

本机测试数据库已应用 0026 迁移。其他部署需应用迁移并设置 `PIWORK_DESKTOP_SYNC_ENABLED=1`。当前 3000 端口 Web 进程未启用该开关，需在其环境启用并重启后使用；桌面用户须在设置中主动启用同步。
